# Windows images 目录联接设计

## 目标

允许 `%LOCALAPPDATA%\CodexDreamSkin\images` 是指向现有本地目录的 Windows 目录联接，使自动换图和图片导入直接使用外部图片目录。

## 安全边界

- 仅放行受管主题仓库的 `images` 根目录联接；其他受管路径继续拒绝任何重解析点。
- `images` 的联接目标必须存在且是目录。
- `images` 内部的文件和子目录不得再次包含联接或符号链接。
- 路径检查必须显式接收允许的联接路径，不能全局关闭重解析点保护。
- 导入、归档和自动换图均直接读写联接目标，用户接受该行为。

## 实现

扩展共享路径检查，使调用方可传入唯一允许的 `images` 根联接。主题仓库初始化、图片归档和自动换图读取复用该参数；活动主题、已保存主题、状态文件和暂停标记保持原检查。

## 验证

- 普通 `images` 目录行为保持不变。
- `images` 根目录联接可初始化、枚举和写入。
- `images` 内的嵌套重解析点仍被拒绝。
- 非 `images` 受管目录联接仍被拒绝。
- Windows 完整回归测试通过。
